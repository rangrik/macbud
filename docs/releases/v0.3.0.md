# MacBud v0.3.0

Launch or switch to any app from the notch — press ⌥⇧A, type a name, hit Return.

- A new **Apps** tab shows what you have been in recently, then the rest of what you use, as a grid you walk with the arrow keys.
- Return switches to an app that is already open instead of relaunching it, so you land back where you left off.
- Search matches app names as you type, putting open and frequently used apps first.
- Ordering comes from macOS's own record of when you last used each app, so the list is useful the first time you open it.
- Open the tab from anywhere with ⌥⇧A, or ⌘5 once the notch is already open.
- A global shortcut that loses a fight with another app now says so under the shortcut in Settings, instead of failing silently.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
