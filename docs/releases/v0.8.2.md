# MacBud v0.8.2

Prediction now keeps one conversation with Codex instead of starting a new one for every guess, so it uses far fewer uncached tokens.

- After the first guess, MacBud tells the model only what changed: what you used after the last open, what you copied, saved or dictated since, and the moment now. The instructions are sent once.
- The conversation lives in MacBud's own Codex sign-in, so it never shows up in your Codex history. Sign in once in Terminal with the command shown in Settings → Prediction. Until then, predictions work as before.
- When the reviewer rewrites its strategies, they go into the same conversation. MacBud starts a fresh one after 40 guesses or once a guess sends 30k tokens; both limits are in Settings → Prediction.
- If the conversation is lost, the next guess starts a new one, and the rules cover you in between. Reset memory starts over too. A relaunch picks up where it left off.
- Prediction Activity shows each call's tokens (how many were cached) and which conversation and turn it belonged to. Today's usage counts cached tokens apart.
- Measured on a real day of use: a guess in the old way cost 4,704 uncached input tokens on average, because half of them missed Codex's cache. A guess in the kept conversation cost about 770.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
