# MacBud v0.9.0

The shelf's prediction now comes from Jev and knows what you were just doing: the app, window title and web page in front.

- Jev picks where the shelf lands, including a named app; Luna answers the same opens in the background so both hit rates stay visible.
- MacBud keeps a local log of the app, window title, web address (host and path only) and focused field type in front, for one day, and sends the last 10 minutes as one line with each model call. Field contents, page text and screen pixels are never read; a password field records only "secure field".
- Nothing is logged while the screen is locked, after 5 idle minutes, with prediction off, or without Accessibility.
- An open with no fresh prediction may wait up to 0.3 s for Jev, then falls back to the rules.
- Prediction Activity shows the exact activity each call saw, and Settings → Prediction shows Jev's results apart from Luna's earlier ones.
- Not tested before release: Safari web addresses and starting dictation while an open waits for Jev.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
