# MacBud v0.8.7

Preview the selected clipboard item, screenshot or app window as soon as you open the shelf.

- Read and scroll text, see full pictures, and inspect links beneath the existing six cards.
- Use the arrow keys to change the preview, or rest the pointer on a card for 150 ms; moving across cards keeps your current selection.
- Empty shelves stay compact. If the first item arrives while the shelf is open, its card and hints stay visible; the preview appears on the next open.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
