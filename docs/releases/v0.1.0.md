# MacBud v0.1.0

MacBud brings clipboard history, snippets, screenshots, on-device dictation, and Keep Alive into the MacBook notch.

- Enable or disable each feature in Settings and choose the order of section tabs.
- Dictate with a shortcut, then press it again to finish and insert into the focused input. Hold to talk is also available; releasing the shortcut finishes the recording. Escape cancels, and text is copied when no editable input is focused.
- Search previous dictations and copy, insert, or save them as snippets.
- Follow the latest transcript automatically while speaking, with synchronized notch expansion and dismissal.
- Keep the Mac and display awake with a compact switch until you turn it off.
- Use the transparent sunrise artwork throughout the app and an adaptive monochrome menu bar icon.

Download `MacBud-0.1.0-macOS.zip`, extract it, and move MacBud.app into Applications. Requires macOS 26 or later. The app contains Apple Silicon and Intel executables; dictation depends on available on-device speech support. Existing settings and saved data are retained when updating.

This optimized Release build is signed with an Apple Development certificate. It is **not Developer ID signed or notarized**, so macOS may block the downloaded app on another Mac. The accompanying `.sha256` file verifies the download's checksum.
