# MacBud v0.5.0

Switch to any window from the notch — press ⌥⇧A, see what is on each one, and hit Return to land there.

- The **Apps** tab now lists **windows**, not just apps. Two Chrome windows are two things you can pick between, each named by its own title.
- Selecting a window shows **a live picture of what is on it**, beside the grid — including windows sitting on another Space or behind everything else.
- Search matches window titles as well as app names, so a word from a page you left open goes straight back to it.
- Return switches to that exact window; for an app that is not running it launches it instead.
- Windows and apps are ordered by when you last used each one, taken from the record macOS already keeps.
- Section tabs no longer disappear under the notch — they flow into the space on its right instead.
- A global shortcut that another app has already claimed now says so in Settings, rather than failing quietly.

Window previews ask for Screen Recording the first time you look at one. Decline and everything else keeps working; the pane shows the app's icon.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
