# MacBud v0.8.4

Prediction now tries a second, much faster model in the shadow, so you can see whether it would do better before it is trusted.

- With a TypeSafe API key in MacBud's app support folder, Jev is asked the same question as the driver whenever your context changes, in about 150 ms, and its pick is scored on every open without changing where the shelf lands.
- Settings → Prediction shows how often Jev would have hit in the last 7 days, next to what the actual landing did on the same opens. Each open in Prediction Activity shows Jev's pick and whether it would have hit.
- Jev sees the same metadata as the driver: app identifiers, item kinds and ages, the reviewer's rules. Never your text.
- Shadow calls stay outside the daily call cap.

Requires macOS 26 or later. Universal (Apple Silicon + Intel). Signed with an Apple Development
certificate and **not notarized**, so macOS may block a downloaded copy.
